Rust Coding Agent

A small coding agent for the terminal, written in Rust. It sends your requests to Anthropic's Claude models and can run shell commands and read, write and edit files in the current directory.

Source Releases Documentation

Install

You need Rust, curl and unzip.

curl -fsSL https://raw.githubusercontent.com/ravshansbox/rust-coding-agent/main/install.sh | sh

Then start it with rust-coding-agent, or rca for short.

Features

  • Sign in with a Claude Pro or Max account
  • Interactive terminal interface with streamed replies
  • Built-in tools: bash, read, write, edit, agent and web_search
  • Print mode (-p) to run one prompt and print the answer
  • Model and effort pickers, with thinking shown in the conversation
  • Saved sessions you can resume, and automatic compaction
  • Status line with tokens, cache hit rate, context use and quota
  • Paste images, @ file picker and prompt history search
  • AGENTS.md instructions and Agent Skills
  • MCP servers over stdio or Streamable HTTP
  • Background updates
